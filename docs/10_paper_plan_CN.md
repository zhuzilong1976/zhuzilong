## 2. 推荐论文的核心论点（一句话）

> 单细胞"虚拟敲除"推断在默认配置下会被**连接度伪影**主导，且在无生物学差异时同样产出"看起来合理"的基因列表；因此**技术对照（同条件分割零分布）不是可选项，而是必需项**。

## 3. 已经有证据支撑的三个具体发现

### 发现 1：显著基因数 = 被敲除基因的出度 + 1

| 网络 | 基因 | 出度 | 显著基因数 |
|---|---|---:|---:|
| Control | CD33 | 146 | **147** |
| Control | BTK | 197 | **198** |
| MS | CD33 | 75 | **76** |
| MS | YKT6 | 145 | **146** |

**机制**：虚拟敲除把目标基因整行出边置零，直接受影响的就是它的靶基因；而 `dRegulation` 用**全局均值**归一化（FC = d²/mean(d²)），于是每个靶基因能否显著取决于它损失了自身输入的**比例**——高连接度枢纽的靶基因只损失极小比例，全部不显著；低连接度基因则相反。

**意义**：按"显著基因数"给基因排优先级是无效的，这是在文献中被广泛使用（本项目最初也这么用）的指标。

### 发现 2：出度为 0 的基因产生退化统计量

同一个"空操作"敲除（出度为 0）在 Control 网络给出 **0 个**显著基因，在 MS 网络给出 **188 个**（p.adj 低至 1e-216）。原因是 WT 与 KO 网络完全相同，Box-Cox + 经验零分布在近乎全零的距离上不稳定。

**意义**：这类基因必须先从分析中剔除，否则会产生极端假阳性。

### 发现 3：技术对照下线，且零分布的 Top 基因同样"合理"

| | 技术对照（同条件半样本） | 实际比较（Control vs MS） |
|---|---:|---:|
| p<0.05 比例 | 5.65% | 7.25% |
| FDR<0.05 | 0 | 0 |
| Top 基因 | SPP1, PFKFB3, CSF2RA, CX3CR1, SLC1A3 | C3, MALAT1, TCF4, SAT1, HLA-DRA |

Fisher p = 0.221。**技术对照的 Top 列表在生物学上同样"讲得通"**——这直接证明"列表合理"不构成证据。

## 5. 与已有文献的区隔

2026 年预印本 *Wu et al., "Method Choice, Not Biology, Determines In Silico Perturbation Results"* 已做 8 方法 × 4 数据集的系统评测，结论是"这类方法非特异"。

**我们的增量（必须在引言中明确写出）**：

1. 他们报告"结果不一致"，我们给出**机制**——一个精确的、可预测的关系式（显著数 = 出度 + 1）
2. 他们指出图方法非特异，我们进一步证明**零分布本身也会产出"生物学合理"的列表**（这是对"用合理性做验证"这一常见做法的直接反驳）
3. 我们提供**可操作的技术对照方案**（分割零分布 + 全基因经验零分布），并给出成本估计
4. 我们的实例来自真实的人类疾病组织（人 MS 病灶小胶质），不是模拟数据

**结论部分的三条实践建议**（论文的核心产出）：

1. 报告任何虚拟敲除结果时，**必须同时报告被敲除基因在网络中的出度**
2. **不要按"显著基因数"给基因排优先级**
